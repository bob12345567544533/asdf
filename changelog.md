# v2.5.0
- **New assists** (all off by default, set them in the F7 window):
  - UFO assist and robot assist: same idea as ship assist.
  - Ledge grace: still jump for a few ticks after running off a block.
  - Late orbs: orbs still activate if you click a few ticks after passing them.
  - Hitbox forgiveness: spikes that only graze the edge of your hitbox don't kill you.
  - Wave assist: nudges the wave a pixel or two away from corners it's about to clip.
  - Danger slow-mo: the game slows down right before you'd die.
- The window is now two columns: sliders on the left, toggles and log on the right.
- **Fixed:** the timing popup now has its own row, so it shows whether or not the counter is on.

# v2.4.0
- **New:** Ship Assist slider (0-50%, default 15%). Softens the ship's vertical acceleration so straight fly is more forgiving. F6 turns it off along with the buffer.
- The window has a second slider for it. Scroll moves whichever slider the mouse is over, arrows move the last one you touched.

# v2.3.0
- The window is now a normal standalone window you can park on a second monitor. It opens on launch (can be turned off), remembers where you put it, and has a live log of saved inputs.
- The ghost player is set up with plain copies again, like v1, instead of helper functions that touched more game state.

- New dark menu with a slider and toggles (F7).
